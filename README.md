BASE DE DATOS - TAREA 1

El proyecto consiste en el diseño e implementación de una base de datos relacional en MySQL para digitalizar el proceso de postulación de iniciativas del Centro Tecnológico USM (CT-USM). La base de datos permite registrar postulaciones, empresas, integrantes y cronogramas, además de gestionar catálogos fijos como regiones, sedes, tipos de iniciativa y estados. Se implementaron relaciones entre entidades mediante claves foráneas y se construyeron consultas SQL que permiten analizar y validar la información almacenada.


• Condiciones de compilación y ejecución:
  el sistema fue desarrollado en PHP con base de datos MySQL (phpmyadmin) y entorno local XAMPP (servicios Apache y MySQL activos).
  El entorno de ejecución debe contar con un servidor local activo

• Instrucción de ejecución:
 - Iniciar el entorno local con XAMPP (servicios Apache y MySQL activos)
 - Ingresar a phpMyAdmin desde el navegador (http://localhost/phpmyadmin/)
 - Ejecutar el archivo 04_ddl.sql para crear la base de datos y las tablas
 - Ejecutar el archivo 05_dml.sql para poblar la base de datos
 - Ejecutar el archivo 06_consultas.sql para probar las consultas requeridas
